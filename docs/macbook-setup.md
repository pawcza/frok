# Terminal Setup Reference

Everything needed to replicate (or adapt to Windows) the terminal environment
built on the MacBook. This file lives at `~/.config/terminal/TERMINAL-SETUP.md`.

---

## Terminal emulator

**macOS → WezTerm** (installed via `brew install --cask wezterm`).
Chosen because it's the only mainstream Mac terminal that **animates a GIF background**
(iTerm2 only shows a static first frame). Config: `~/.config/wezterm/wezterm.lua`.

**Windows → Windows Terminal** already supports animated GIF backgrounds natively,
so no special terminal needed. Drop the same `matrix.gif` into the Windows Terminal
`backgroundImage` setting.

## Font

**PT Mono** size 14, matching iTerm2. System font on macOS (`/System/Library/Fonts/Supplemental/PTMono.ttc`).
On Windows, install PT Mono from Google Fonts.

Fallback chain in WezTerm: PT Mono → CaskaydiaCove Nerd Font (icons/glyphs, installed
via `brew install --cask font-caskaydia-cove-nerd-font`) → PingFang HK → Menlo.

Smoothing on macOS: `freetype_load_flags = 'NO_HINTING'` (disables FreeType pixel-snapping
to match the softness of macOS native / iTerm2 rendering).

Ligatures enabled: `harfbuzz_features = { 'calt=1', 'liga=1' }`.

## Matrix rain background

An animated GIF (`~/.config/wezterm/matrix.gif`, ~9 MB) generated by a Python script
(not downloaded — custom, no licensing issues).

- **Generator**: `/private/tmp/.../scratchpad/matrix_gen.py` (or regenerate with the
  approach below).
- Uses Pillow + the Hiragino katakana font for authentic glyphs.
- **Seamless loop**: each column is a fixed vertical strip that scrolls down by an exact
  whole number of strip-heights over the animation → offset returns to 0 → no visible seam.
  190 frames at 50ms (20fps). Mostly k=1 (slow, calm fall).
- Color: classic phosphor green `#00FF41`, bright white drop-heads.
- Verify loop: `mean_abs_diff(last_frame, first_frame)` should ≈ `diff(frame0, frame1)`.

In WezTerm, the GIF is dimmed via two background layers:
```lua
config.background = {
  { source = { File = { path = '~/.config/wezterm/matrix.gif', speed = 1.0 } },
    hsb = { brightness = 0.45 }, width = 'Cover', height = 'Cover' },
  { source = { Color = '#000000' }, width = '100%', height = '100%', opacity = 0.74 },
}
config.text_background_opacity = 0.0
```
**Windows Terminal equivalent**: set `backgroundImage`, `backgroundImageOpacity: 0.15`,
`backgroundImageStretchMode: "uniformToFill"`.

## Color scheme

Classic Matrix green. Foreground `#00FF41`, background `#000000`.

ANSI palette (green shades): `#0D0D0D #00A32E #00FF41 #39FF14 #005F15 #00C853 #1BFF6B #9DFFB0`.
Brights: `#1A1A1A #00C853 #39FF14 #6BFF7A #008F28 #00E676 #4DFF88 #CFFFD8`.

Tab bar: black bg, active tab `#005F15`/`#CFFFD8`, inactive `#0A0A0A`/`#00A32E`.

## Startup layout (WezTerm gui-startup)

Two columns, maximized window with title bar (`TITLE | RESIZE`).

| Pane | Column | Size | CWD | Runs |
|------|--------|------|-----|------|
| top-left | left | 1/8 height | ~/dev | `companion` (animated frog) |
| mid-left | left | 2/8 height | ~/dev | plain shell |
| bottom-left | left | 5/8 height | ~/dev/personal | `ccs personal` |
| right-top | right | 50% | ~/dev/personal | `ccs personal` |
| right-bottom | right | 50% | ~/dev/personal | `ccs personal` |

Programs are launched via `args = { '/bin/zsh', '-ic', 'cmd; exec /bin/zsh -i' }` (not
send_text, which races shell init and triggers zsh autocorrect garble).

The split runs only AFTER the window stops resizing (polls `get_dimensions().pixel_height`
every 0.2s until stable), otherwise the async maximize skews the fractions.

## Companion (the frog)

An animated ASCII frog that reacts to **every Claude Code session** via hooks.

### Files
- `~/.config/terminal/frog.txt` — the 6-line ASCII frog art (stored as a plain file
  to avoid shell quoting hell with its apostrophes/backslashes).
- `~/.config/terminal/claude-companion.sh` — the renderer (zsh script). Draws frog
  on the left, mood label + useless fact + hotkeys on the right. ~5 fps, absolute
  cursor positioning (no jumping). Eyes blink `(')` → `(-)`.
- `~/.config/terminal/companion-event.sh` — the hook bridge. Reads Claude Code's hook
  JSON on stdin, maps `hook_event_name` → mood, writes `<ts> <mood>` to
  `companion.state`. Also writes per-session state to `sessions/<session_id>`.

### Mood mapping (from hook events)
| Event | Mood | Frog color |
|-------|------|------------|
| UserPromptSubmit | thinking | light green |
| SubagentStart | working | cyan |
| Stop | done | light green |
| Notification / PermissionRequest | waiting | yellow |
| PostToolUseFailure | error | red |
| PreCompact | dizzy | cyan |
| SessionStart | wake | light green |
| SessionEnd | sleep | dim green |

### Useless facts
Instead of canned tips, the companion fetches a random fact from
`https://uselessfacts.jsph.pl/api/v2/facts/random?language=en` (`.text` via jq).
Fetched in the **background** (`{ curl … } &!`) into `~/.config/terminal/.fact`;
the draw loop reads the file each frame (never blocks). Any key → new fact.

### Hooks
Hooked into the same 9 events as peon-ping, appended ALONGSIDE peon in
`~/.claude/settings.json` (backup at `settings.json.bak.companion`):
SessionStart, SessionEnd, SubagentStart, UserPromptSubmit, Stop,
Notification, PermissionRequest, PostToolUseFailure, PreCompact.

## WezTerm status bar (always-on top bar)

`hide_tab_bar_if_only_one_tab = false` so the top bar always shows.

Right-status shows (via `update-right-status` event):
1. **Companion mood face** (`( o.o )` etc.) — reads `companion.state`, decays
   transient moods to idle after 12s.
2. **Current folder** — from `pane:get_current_working_dir()` (requires OSC 7 from shell).
3. **Git branch** — from user var `WEZTERM_GIT` (set by a zsh `precmd` hook via
   `SetUserVar` OSC).
4. **Clock** — `HH:MM`.

Refreshes every 1s (`status_update_interval = 1000`).

## Shell config

All additions live in `~/.config/terminal/claude-terminal.zsh`, sourced by ONE line
at the end of `~/.zshrc`:
```
[ -r ~/.config/terminal/claude-terminal.zsh ] && source ~/.config/terminal/claude-terminal.zsh
```

Contains: tool aliases (eza/bat/zoxide/fzf/lazygit), WezTerm shell integration
(OSC 7 for cwd, SetUserVar for git branch), Starship prompt init, and the
`companion` alias.

**Windows**: equivalent would be a PowerShell profile block or WSL `.zshrc`.

## Starship prompt

Config: `~/.config/starship.toml`. Currently **Tokyo Night** theme (user-modified
from the original matrix-green). Shows: directory (full path) → git branch → git
status → node version → cmd duration → character prompt.

## Per-pane status bars

WezTerm does **NOT** support per-pane title/status bars (a known gap vs iTerm2).
One window-level status bar only.

## Known gotchas

- **Font changes hot-reload** but re-flow the pane splits and skew proportions.
  After changing the font, restart WezTerm to get clean splits.
- The pane `cwd=` option isn't reliably honored for `args`-launched panes.
  Use `cd "<dir>" &&` in the command instead.
- `wezterm cli send-text` defaults to bracketed-paste mode. Use `--no-paste` or
  the Enter doesn't fire.
- User's zsh has `setopt correct` (autocorrect) + `noclobber`. Use `>|` for
  force-redirect in test scripts; use `command cat` instead of `cat` (aliased to bat).
